小巧好嵌

Session + Agent + 工具 — 莫得文件编辑、终端、MCP 那些花架子，循环你自己捏，撇脱。

边跑边看

支持流式输出，聊天界面巴适；要接 UI 了，文档里头一步一步摆清楚。

OpenAI 那套 API

OpenAI、DeepSeek、Ollama、vLLM、SGLang 等，只要兼容 /v1/chat/completions，莫得问题。

二十几行就整一个 Agent ​

点一个模型标签，钥匙设好，存成 demo.py，直接 搞起 python demo.py。模型要得的时候会调 @tool，答案在 result.content 里头，安逸。

python
import asyncio
import os

from pagent import LLM, Agent, Session, tool


@tool()
def get_weather(city: str) -> str:
    """Return weather for the city."""
    return f"Sunny in {city} today."


async def main():
    if not os.getenv("OPENAI_API_KEY"):
        raise SystemExit("Set OPENAI_API_KEY first.")

    agent = Agent(
        llm=LLM("gpt-4o-mini"),
        session=Session("You are helpful. Use tools when needed."),
        tools=[get_weather],
        max_turns=8,
    )

    result = await agent.run("What's the weather in Xiamen?")
    print(result.content)


asyncio.run(main())
