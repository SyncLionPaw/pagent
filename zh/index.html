小而可嵌入

Session + Agent + 工具 — 不带文件编辑、终端或 MCP，循环由你掌控。

流式事件

Python 用 arun_events()；前端/插件用 arun_wire() 输出 JSON-RPC NDJSON。

OpenAI 形态 API

支持 OpenAI、DeepSeek、Ollama、vLLM、SGLang 等兼容 /v1/chat/completions 的服务。

安装 ​

bash
pip install pagent
pip install "pagent[search]"   # 可选 web_search

需要 Python 3.11+。完整示例见 快速开始。
